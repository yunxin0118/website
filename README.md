# 🧑‍💻 個人網頁作品 – Portfolio Website

這是一個以 HTML、CSS、Bootstrap 和 Font Awesome 所製作的個人作品集網站，展示了我的大學經歷、興趣、工作經驗與聯絡方式。此網站支援 RWD 響應式設計，並搭配動畫與互動效果，提升使用者體驗。

---

## 🔍 功能特色 Features

- 🎓 **大學在學經歷**：以時間軸方式呈現各學期活動與成果  
- 💼 **工作經驗**：條列式顯示職場經歷，並可下載個人履歷（PDF）  
- ✨ **動畫與視覺效果**：進入時的滑動動畫與背景透明圖層  
- 📱 **RWD 響應式設計**：適用於手機、平板、桌面  
- 📮 **聯絡方式區塊**：整合 Email、電話、IG、FB 與 GitHub 連結

---

## 🛠 使用技術 Tech Stack

- HTML5 / CSS3  
- Bootstrap 5  
- Font Awesome Icons  
- JavaScript  
- AOS.js
